## 🎒 What does DankTech2 do?

DankTech2 is a Slimefun-only rewrite of Sefiraat's earlier DankTech project. The idea was inspired by Minecraft mod concepts such as **Dank Storage**, **/dank/null**, and **OpenBlocks /dev/null**, reimagined as a Slimefun addon.

Core features include:

- **9 tiers of Dank Packs**, with increasing slot counts and per-slot capacity;
- **9 tiers of Trash Packs**, which automatically void matching items instead of storing them;
- automatic pickup filtering into the correct pack/slot;
- optional overflow voiding so excess items do not clog player inventories;
- withdrawing items individually, by stack, or into available inventory space;
- depositing matching items from a player's inventory;
- a Cargo-compatible unloader;
- using stored blocks from a Dank Pack while building.

## 🧪 Slimefun Legacy maintenance

This fork keeps DankTech2's established storage behavior and item identity while maintaining it for the modern Slimefun Legacy ecosystem. Storage plugins deserve extra caution: back up worlds, player data, and plugin data before replacing production builds, and test high-capacity packs with low-value items first.
